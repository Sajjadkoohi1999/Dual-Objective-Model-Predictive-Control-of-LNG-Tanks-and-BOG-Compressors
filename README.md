# Dual-Objective-Model-Predictive-Control-of-LNG-Tanks-and-BOG-Compressors
A dual-objective model predictive control strategy is developed for LNG storage systems to minimize boil-off gas energy loss while maintaining tank pressure within safe operating limits. The nonlinear differential-algebraic equation model is simulated using OpenModelica and MATLAB, with automatic differentiation and successive linearization employed to handle nonlinear dynamics, and an extended Kalman filter incorporated to address model mismatch. Results show a 16.8% reduction in energy loss compared with set-point tracking MPC and a safer operating margin than economic MPC, which operates closer to constraint boundaries.
